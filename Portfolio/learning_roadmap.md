# My Software Developer Learning Roadmap

## Semester 1: Foundation
- Learn programming fundamentals using Java.
- Understand variables, loops, conditions and functions.
- Learn basic HTML and CSS.
- Practise Git and GitHub.
- Complete the Developer Portfolio project.

## Semester 2: Problem Solving
- Learn Java Object-Oriented Programming.
- Start Data Structures and Algorithms.
- Learn SQL and database fundamentals.
- Practise basic JavaScript.
- Complete one beginner-level certification.

## Semester 3: Web Development
- Learn JavaScript in depth.
- Learn frontend development.
- Understand backend development fundamentals.
- Build small practical projects.

## Semester 4 and Beyond: Career Preparation
- Build full-stack projects.
- Practise coding problems regularly.
- Learn software development tools and workflows.
- Improve communication and interview skills.
- Prepare for internships and placements.

## Career Goal
My goal is to become a Software Developer. I will improve my programming, problem-solving and project-building skills through regular practice.
